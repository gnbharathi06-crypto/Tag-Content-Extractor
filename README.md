# Tag Content Extractor

This repository contains my Java solution for the HackerRank
**Tag Content Extractor** challenge.

## 📝 Problem Description

In a tag-based language such as HTML or XML, content is enclosed
between a start tag and an end tag.

The task is to extract the valid content enclosed within matching
tags.

### Rules
- The start and end tag names must match.
- Tags can be nested.
- Content between nested tags is not considered valid.
- Tags can contain printable characters.
